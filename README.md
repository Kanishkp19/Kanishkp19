### 🚀 Featured Engineering & Architectures

* **👁️ [Argus](https://github.com/Kanishkp19/Argus)**
  > **Industrial Knowledge Intelligence Platform:** Ingests P&ID schematics, SOPs, and maintenance logs into a unified KùzuDB knowledge graph. Features a sub-second Corrective RAG (CRAG) loop with an automated safety contradiction engine cross-checking work orders against operating procedures.

* **📞 [ai-calling-agent](https://github.com/Kanishkp19/ai-calling-agent)**
  > **Autonomous Voice Agent:** Ultra-low latency voice conversational agent designed for automated outbound/inbound telephone workflows, combining real-time streaming speech-to-text (STT), LLM reasoning, and natural text-to-speech (TTS) synthesis.

* **🛡️ [Wikisentinal](https://github.com/Kanishkp19/Wikisentinal)**
  > **Real-Time Vandalism Mitigation:** High-throughput stream processing architecture coupled with multi-modal AI agents to detect, flag, and mitigate Wikipedia vandalism in real-time.

* **🧠 [Adaptive_learning](https://github.com/Kanishkp19/Adaptive_learning)**
  > **Intelligent Pedagogical Engine:** Dynamic educational platform that models student comprehension curves and adjusts curriculum difficulty, quiz generation, and review intervals in real time.

* **🎭 [Multimodal_Emotional_Regualtion_Analysis](https://github.com/Kanishkp19/Multimodal_Emotional_Regualtion_Analysis)**
  > **Affective Computing & Signal Analysis:** Multimodal deep learning pipeline processing synchronous visual, vocal, and textual features to map and analyze emotional regulation patterns.

* **👗 [VTON_MODEL-](https://github.com/Kanishkp19/VTON_MODEL-)**
  > **Virtual Try-On Generative Pipeline:** Conditional deep generative framework executing high-fidelity 2D garment warping and human pose synthesis while preserving fine fabric textures and complex garment folds.
